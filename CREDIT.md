## Adding a new cloned skill

1. Copy the skill folder in (see "Adding New Skills" in `README.md`).
2. Add a row to the table above with the skill name, source repo link, and
   its license (check the source repo's `LICENSE` file — don't assume MIT).
3. Add or update the corresponding row in the "Skill Sources" table in
   `README.md`.
